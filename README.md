# 🌐 HTML Basics Repository

This repository contains all the fundamental concepts of **HTML (HyperText Markup Language)** used to build the structure of web pages.

It is designed for:
- 🎓 Beginners learning Web Development
- 💻 Students preparing for exams
- 🚀 Developers revising core HTML concepts
- 🧠 Interview preparation

---

## 📌 Topics Covered

### 🔹 1. Introduction to HTML
- What is HTML?
- Structure of an HTML Document
- HTML5 Overview
- DOCTYPE Declaration

---

### 🔹 2. Basic Tags
- Headings (`<h1>` to `<h6>`)
- Paragraph (`<p>`)
- Line Break (`<br>`)
- Horizontal Line (`<hr>`)
- Comments
- Formatting Tags
  - `<b>`, `<strong>`
  - `<i>`, `<em>`
  - `<u>`
  - `<mark>`
  - `<small>`
  - `<sub>`, `<sup>`

---

### 🔹 3. Links & Images
- Anchor Tag (`<a>`)
- Image Tag (`<img>`)
- Absolute vs Relative Paths
- Target Attribute

---

### 🔹 4. Lists
- Ordered List (`<ol>`)
- Unordered List (`<ul>`)
- Description List (`<dl>`)

---

### 🔹 5. Tables
- Table Structure
- `<table>`, `<tr>`, `<th>`, `<td>`
- `colspan` & `rowspan`
- Table Styling Basics

---

### 🔹 6. Forms
- Form Structure
- Input Types
  - text
  - password
  - email
  - number
  - radio
  - checkbox
  - file
- Labels
- Buttons
- Textarea
- Select & Option
- Form Validation Basics

---

### 🔹 7. Semantic HTML5 Tags
- `<header>`
- `<nav>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`
- `<main>`

---

### 🔹 8. Multimedia
- Audio Tag
- Video Tag
- Iframe

---

### 🔹 9. HTML Entities
- `&nbsp;`
- `&lt;`
- `&gt;`
- `&copy;`

---
